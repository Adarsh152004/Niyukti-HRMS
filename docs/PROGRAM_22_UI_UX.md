# Program 22: UI/UX Quality, Accessibility & Design Standards

## 1. Enterprise Design Philosophy
- **Restraint & Information Density**: Clear data hierarchy, modest padding, and zero visual clutter.
- **Color Discipline**: Warm slate neutral base with semantic indicators (Emerald `#10B981`, Amber `#F59E0B`, Crimson `#EF4444`, Indigo `#4F46E5`).
- **Dark Mode**: Dark graphite surfaces with high-contrast readable typography.
- **Zero AI Slop**: No excessive glowing purple borders, animated rainbow backgrounds, or oversized empty cards.
